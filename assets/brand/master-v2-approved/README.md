# Zone Sketch brand v2 — approval pack

This folder is the **approved visual reference pack** for the next Zone Sketch identity pass.

## Locked visual direction

- Primary mark: a **clear house silhouette**, not an abstract/blob shape.
- House: **glossy blue → cyan → green gradient**.
- Main flame: **red**, with layered red/orange glow and a glossy highlight.
- Main icon combines the three product families: blue/security-CCTV, green/access control, red/fire.
- Fire variant: red.
- CCTV variant: blue.
- Access Control variant: **green**.
- Mono variant: white/grey.
- Dark blueprint/grid background and glossy neon treatment are part of the approved visual style.

## Source of truth

`approved-board.webp` is the exact board approved in chat and is intentionally stored unchanged as the visual source of truth for the integration review.

Do **not** redraw, reinterpret, simplify, recolour, crop from another mock-up, or regenerate the icon during app integration without a separate approval pass.

## Integration status

**NOT YET IN THE APP.**

This folder and the `brand-v2-approval.html` page are for approval only. The existing Zone Sketch launcher icon, splash screen, PWA manifest and in-app branding should remain unchanged until Will approves the v2 integration preview.

## Next step after approval

Create production-resolution app/export assets from this locked visual reference, then integrate them into the tester portal first and verify iPhone/iPad/Android rendering before replacing the full app branding.
