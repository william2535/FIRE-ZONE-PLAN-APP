# Zone Sketch master brand assets

These are the production master assets for the Zone Sketch identity.

## Canonical primary mark
`zone-sketch-mark-primary.svg` is the locked master mark:
- house stays a clear architectural house silhouette;
- house stroke uses the blue → cyan → green gradient;
- central fire mark is red/orange with layered glossy glow;
- dark blueprint/grid background is part of the app-icon treatment.

The primary mark deliberately combines the three product disciplines:
- **red** = fire;
- **blue** = CCTV/security;
- **green** = access control.

## Discipline variants
- `zone-sketch-mark-fire.svg` — fire variant.
- `zone-sketch-mark-cctv.svg` — CCTV/security variant.
- `zone-sketch-mark-access.svg` — access-control variant in industry-standard green.
- `zone-sketch-mark-mono.svg` — documentation/print-safe mono variant.

All discipline marks reuse the same house geometry. Do not redraw or regenerate the house shape.

## Wordmark and splash
- `zone-sketch-wordmark-primary.svg` — master wordmark.
- `zone-sketch-splash-primary.svg` — launch/splash artwork.

## Colour anchors
- Blueprint navy: `#02070E`
- CCTV blue: `#18C8FF` / `#2BA6FF`
- Access green: `#8CFF3F`
- Fire red: `#FF2D27`
- Fire orange: `#FF6B2C`
- Flame highlight: `#FFF2B0`

## Production rule
Use the SVG masters directly on web/tester portal wherever possible. Generate required PNG sizes directly from these SVGs. Never crop the moodboard, a screenshot, or an AI preview to create an app icon.

This folder is intentionally separate from the currently deployed app assets until the new identity is approved for full app rollout.
