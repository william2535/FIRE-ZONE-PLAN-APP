# v0.64 — keyboard shortcuts and device photos

## Changes

- Project → App settings → Keyboard shortcuts: 14 configurable single-key actions, disable/unassign/reset, duplicate-key rejection and local preference persistence. Standard Ctrl/Command Undo/Redo remain available. Typing, dialogs, Home and Circuit Builder are protected from drawing shortcuts; Plan-only actions do not edit Survey buildings.
- Device Properties now contains camera/gallery attachment controls, up to six compressed 1200px JPEG photos per device, captions and independent removal. Photo/caption edits save immediately and participate in Undo. Attachments belong to the symbol rather than a separate floating pin and travel with floors, project copies, snapshots and editable backups. Plan PNG/PDF outputs do not include this gallery.
- Async attachment resolves the original project/floor/device after decoding; a changed or deleted target cannot receive a misplaced attachment. Backup validation rejects malformed galleries and non-embedded image URLs.
- Android capture input launches the external camera with a narrowly granted temporary content URI. The existing provider keeps exports read-only; only the capture cache accepts camera writes. Picker cancellation returns no attachment. Gallery selection remains available; image/PDF imports now pass their MIME types to Android.
- Updated the beta guide and matching download page. Protected 24/7 demo files remain unchanged.

## Verification

`node tests/device-photos-keybinds.cjs` exercises browser file-chooser capture/gallery paths, caption persistence, six-photo limit, removal/Undo/Redo, IndexedDB reload, editable backup validation/import, custom-key persistence, duplicate keys, disabled shortcuts and typing/dialog/Home guards at phone and tablet widths. It does not emulate a physical camera.

The full existing browser regression runner includes this test. Release metadata and four HTML copies are checked by `tests/release-v064.cjs`. The Android build workflow compiles the wrapper and publishes the APK only after its gates pass.

## Physical device check

On Android install the updated APK, take a device photo, cancel another capture, rotate the device and reopen the project. On iPhone/iPad use Take photo and Choose photo, then export and import an editable backup. Camera chooser behaviour depends on the device/browser. No physical-device camera test is claimed by the automated browser suite.
