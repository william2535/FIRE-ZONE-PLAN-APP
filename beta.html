FIELD GUIDE · CHECKED AGAINST BUILD 0.63 · 5 OCTOBER 2026

From first plan to office handover.

A step-by-step guide to Zone Sketch. Start with the practice project, or jump straight to the tool you need. Control names follow the current beta; older installed builds may differ.

01 · Your first complete project

Start with a small practice floor: two rooms, one zone, a fire panel and three smoke detectors. This lets you learn the complete workflow before using a large site plan.

  1. Use Start testing → Open web beta, or install the Android APK. On Home, choose Make a new plan, enter the site name, select Fire and create the project.
  2. Choose Start blank canvas or Import floor plan. In Building layout, use Box to draw two rooms.
  3. Choose ＋ Zone, enter a number, area description and colour, then save. Choose Zone → Fill area and tap inside each enclosed room.
  4. Open Survey mode → Add device. Place a Fire panel and three Smoke devices. Use two fingers to move or zoom the view.
  5. Open Circuit Builder → Highlight a loop. Tap or sweep across the three detectors, then choose Build highlighted loop.
  6. Start at the green-ring FAP, drag a route through the devices, then return to the FAP when prompted. Choose Keep circuit ✓.
  7. Choose Finish As-Fit, review the drawing and export the PNG. Back in the main workspace, try Export → Site survey → Current floor PNG too.
  8. Finish with Project → Save editable backup. Return to Home and reopen the project to practise continuing a saved job.

Plan establishes the building. Survey places the devices. Circuit Builder records their routes. Exports turn that work into a drawing you can hand over.

02 · Open the beta and find your way around

The Start testing tab has the current web build, Android download and feedback form. The web build works in a browser; iPhone and iPad users can open it in Safari and use Share → Add to Home Screen (enable Open as Web App if offered).

On Android, download the APK and follow your device’s installation prompts. Export your existing projects before uninstalling an old build. Browser projects and APK projects are separate stores; transfer an editable backup to move work between them.

The Home screen groups projects by Fire, Security, CCTV and Access Control. The general drawing workflow is shared, while symbols and system setup change with the chosen system. The fire circuit instructions below refer specifically to Fire projects.

On smaller screens the header collapses. Open Menu to reveal Project, Drawing, Survey mode, Circuit Builder and Export. Close ▲ folds it away again. The Home logo returns to projects. Menus at the bottom hold drawing tools; the floor control identifies the current floor.

Project data is stored locally. Open and check the build before leaving for site; saved local data does not by itself guarantee a browser can load the app without a connection.

03 · Create, organise, save and transfer projects
  1. Choose Make a new plan, give it a recognisable site name and select its system.
  2. Use the Home search and system cards to find recent work. Choose Show all if a project seems missing from a filtered list.
  3. On a project card, Open continues the job, Rename changes its name and Duplicate creates a separate copy for an alternative or practice edit.
  4. Export on the card saves the editable project. Inside the drawing, use Project → Save editable backup. Keep the downloaded .zonesketch.json file.
  5. To continue on another device, transfer that file and choose Import backup on Home or Project → Open backup.

Autosave runs locally as you work. Check the save status before closing. A PNG or PDF is a drawing output, not an editable backup. Backups preserve floors, devices, photos and circuits.

Delete on a project card removes that project from this device and cannot be undone. Browser-data clearing, private browsing and uninstalling can also remove local work. Keep a backup outside the app before major changes and at the end of a visit.

04 · Import a plan, clean it up or start blank

Choose Import plan for a photo, PNG, JPG or PDF. For a multi-page PDF, enter the page number containing the floor plan. PDF pages are rasterised for tracing; this does not import editable CAD walls. Add other pages to their corresponding floors separately.

Start blank canvas gives you a drawing surface without a reference image. Blank this floor replaces the current floor’s work; read the confirmation and back up first. Importing over an existing plan also clears that floor’s drawing and labels after confirmation.

  • Picture opacity: fade a reference so drawn walls are easy to see.
  • Hide picture / Show picture: control whether the background is visible, including in the drawing export.
  • Clean up: adjust brightness, contrast and black-and-white treatment, try the Plan preset or reset the adjustments.
  • Perspective: place the four numbered handles on the photographed plan’s corners, then Apply. Do this before tracing.

Imported plans are resized to keep the app responsive. Use the clearest original available. Rotating the imported picture in Clean up is different from rotating the entire floor in Canvas options.

05 · Move, zoom, grid and canvas space
WorkspaceHow to work
Plan / Zone MakerMove ON navigates the view. Turn it OFF or select a drawing tool to draw. Enable Move for two-finger navigation in this mode.
SurveyOne finger places the selected device. Two fingers move and pinch-zoom. Choose Select / move to edit or drag a device.
Circuit BuilderOne finger draws from the current green-ring device. Two fingers navigate. Use −, + or Fit to adjust the view.

Use Fit to recover the whole drawing if you lose your place. The main canvas zoom controls include a zoom slider and percentage. On a desktop, the mouse wheel also adjusts zoom.

Drawing → Build mode ON · Separate keeps placing zones and moving them as separate actions. With OFF · Place + move, dragging an existing zone can move it while a zone placement tool remains selected. This is useful on small plans; use ON when you want more deliberate editing. Build mode is separate from Move ON/OFF.

Grid controls visibility; Snap controls alignment in Plan mode. In Plan mode, open the canvas ⋯ menu for spacing from 2 to 250. Smaller values give finer placement. These are drawing-grid values, not calibrated real-world dimensions.

Survey has Grid − / Grid + and an always-on Device snap. Changing the Survey grid can realign existing surveyed devices, so choose a suitable spacing before routing circuits. Hiding the grid does not disable device snapping.

In Plan mode, in canvas ⋯, Add space around plan adds a 25% border on each side. Rotate floor 90° rotates the current floor and background together. Both support Undo.

06 · Draw rooms, walls, doors and openings

Work in Plan / Zone Maker → Building layout. Choose Wall and drag each segment. Nearby wall ends snap together; intersections create smaller sections you can edit separately. Pen is freehand.

  • Box: drag opposite corners to create four walls.
  • Outline: tap successive building corners, then choose Finish outline.
  • Circular room: drag a circle or oval; it becomes editable wall sections.
  • Corridor: drag a corridor box to create grouped walls and a Corridor label.
  • L-shaped room: drag the outside size, then rotate or mirror the resulting selection if needed.
  • Room label: tap and enter a name. Quick room names let you repeatedly place Office, Store, Corridor, WC, Plant room or a custom label.

Open Objects for Door, Double door, Window, Roller shutter and Stairway. Drag along an existing wall to place an opening. The orange preview shows its width; your finger’s side of the wall sets a door’s swing. For stairs, drag a rectangle; the drag direction sets the up arrow.

A door can be deleted independently. Its cut opening may remain: use Wall to draw across the gap if you want it closed again.

For corrections, use Edit wall ends and drag a blue endpoint; Trim / Extend near a wall end; Join wall gap by tapping the two endpoints; or Split wall where a new junction is needed.

07 · Add coloured zones and edit objects
  1. Choose ＋ Zone in the side panel or Zone → Create zone.
  2. Enter the zone number, area description and colour, then Save zone.
  3. With that zone selected, choose Box and drag, Outline and tap corners then Finish outline, or Fill area and tap inside enclosed drawn walls.
  4. Repeat for disconnected rooms belonging to the same zone. Create another zone when you need a different number or area.

Fill area needs a closed boundary made from the app’s walls. Lines in an imported image are only pixels: trace them first. If fill fails, zoom in and close small gaps. Zone names and numbers appear in the zone index and exported key rather than covering the drawing.

Select / Move selects an object for dragging. Box select selects several; choose Group to keep them together or Ungroup to separate them. Blue corner handles resize a selection. The selection bar also offers Duplicate, Rotate 90°, Mirror, Properties and Delete selected.

Delete can remove tapped or swiped items; Undo restores the last change and Redo reapplies it. Locks protect the background, building or zones. Layers hides working-view content; it is not an export exclusion control.

08 · Work across Ground, First and other floors

Open the floor control to switch floors or choose ＋ Add floor. Select Ground floor, First floor, Second floor, higher floors, Basement, Mezzanine or Custom. Use Rename for the site’s actual floor names.

When adding a floor, Copy current building layout copies walls, doors, double doors, windows, shutters, stairs and room labels onto a blank plan. It does not duplicate the original background photo, zones or notes. Add and check the new floor’s devices and zones separately.

Each floor keeps its own plan, zones, surveyed devices, circuits and As-Fit state. Confirm the floor name before drawing or routing. Circuit Builder also has a floor selector; switching there opens the selected floor’s circuit list.

Current floor PNG exports one floor. All floors PDF collects the building. Deleting a floor removes its contents, so export an editable backup before doing so.

09 · Survey devices, colours, references and favourites
  1. Open Survey mode. The building follows the Plan layout; edit fire-project walls back in Plan mode.
  2. Choose Add device, then a type. Fire options include MCP, Smoke, Heat, Beam detector, Sounder, Beacon, Fire panel, Repeater and I/O unit.
  3. Choose Symbol colour and Size before placement. Tap to stamp ordinary devices repeatedly. For a beam, press at its start, drag the triangle tip and release.
  4. Choose Select / move, then tap or drag an existing device. Open Properties to change its reference, note, type, colour or size; choose Save to apply.
  5. For a frequent combination, select the device, colour and size, then Save current to side or Favourites → Save current device.

You can keep up to nine Survey favourites. Each stores type, colour and size; tap one on the side to place that combination immediately. This is separate from the general Favourite tools menu, where a long press on a menu tool adds or removes a shortcut.

Add multiple devices accepts quantities for several types, up to 100 devices per batch. These are ordinary individual symbols: move them to their real positions afterwards. Automatic placement is a starting arrangement, not a coverage calculation.

Devices shows counts for the current floor and whole building. Fire Plan mode only displays Panel, Repeater and You are here symbols; use Survey to inspect the detector layout. New-symbol colour and size settings do not automatically restyle existing devices.

10 · Security, CCTV and Access Control projects

Choose the system when creating the project. Open System tools for that system’s available devices and setup fields. Use the shared Plan workspace for the building and Survey for placing and editing equipment.

For CCTV cameras, press at the camera position and drag to aim, or tap to place facing right. Selected-camera Properties includes Camera direction. The triangle indicates pointing direction, not measured coverage.

Where a device offers System setup, open it to record the relevant system information. Access Control has door associations; Security has its own labels and map information. Use Layers to simplify the working view when needed.

For tools that offer a connection route, follow the on-screen prompts and use Undo bend, Save route or Cancel connection. Do not assume the fire addressable-loop workflow applies to every system. The system-specific controls are the guide for the selected job.

11 · Site notes, photos and drawing details

In Site details, choose Pinned note or Pinned photo, then tap the exact location. Enter the note or choose the site image. Pins retain their location and are listed in the office export. Use them for access problems, unidentified equipment or things the office needs to check.

Project → Drawing details records the drawing reference, revision, surveyed-by name and survey date. Fill these in before producing a handover so the recipient can identify the site visit and drawing.

Photos increase backup size and can make long exports larger. Keep the relevant images and check the exported document before sharing it.

12 · Circuit Builder: zones and addressable loops

Prepare the current floor first: draw zones for zone challenges and place the actual field devices plus a Fire panel / FAP in Survey. Open Circuit Builder.

Zone challenge / conventional circuit

  1. Choose a zone from the list. Devices inside its drawn areas are picked up for the challenge; an empty zone cannot start.
  2. Start on the green-ring FAP and drag through the devices in the order you want to record. Lift your finger when necessary, then continue from the current green-ring device.
  3. The counter updates as devices are connected. Existing zone routes remain on the board. Crossings are blocked with Bridge OFF; enable Bridge for a deliberate crossover that should be marked.
  4. Connect all assigned devices to complete the conventional circuit. Unlike an addressable loop, it does not require a return to the FAP.

Addressable loop

  1. Choose Highlight a loop, then tap or sweep over its devices. Use Clear highlighted to restart the selection.
  2. Choose Build highlighted loop. Start at the FAP and route through every selected device.
  3. When the counter prompts RETURN TO FAP, draw the return. The return magnet / twin-cable snap helps pair nearby runs; inspect the result before keeping it.
  4. Choose Keep circuit ✓. Use Undo last leg for a local correction or Retry run to start the route again.

Pinch with two fingers to navigate while routing. The +, − and Fit controls are useful on crowded boards. Sound can be toggled in Circuit Builder; App settings also controls sounds, haptics and reduced motion. A completion reward means the drawn route met the app’s routing checks, not that the installed system has been tested.

13 · Correct routes and generate an As-Fit

Reopen a created circuit to continue it. Undo leg removes the last routed leg; Reset clears the run. If Survey devices moved or were removed, the circuit may need rebuilding. Read the warning: confirming a rebuild clears the old route and uses the available current positions.

Use the circuit’s pencil / edit control for Manual Edit. Draw the replacement cable first with Pencil, then use Bin to remove the old section. Edit has its own Undo and Redo. The Cleanup control affects processing after you lift your finger. Turn on Bridge when an intentional crossing needs a mark.

Choose Done ✓ to validate and save the edit. If the route is open or invalid, follow the message and reconnect the gap. An unfinished edit can block As-Fit generation.

Finish As-Fit becomes available when all created circuits on that floor are complete and valid. Review any warning about unassigned devices before continuing. Inspect the preview, then choose Export As-Fit PNG.

For recorded survey / installation status, open Project → Maps & As-Fits. Choose an item, set its record state and note, and only mark the onsite-check checkbox when you have actually checked it. Enter issuer details, revision and a note before Issue As-Fit snapshot. Issued snapshots preserve the project at that moment; they do not certify compliance. Working records CSV exports the recorded item information.

15 · Quick fixes when something feels wrong
I cannot find a control.
Expand Menu on a phone. Check Project, Drawing or the bottom tool menus. Confirm whether you are in Plan, Survey or Circuit Builder.
Dragging moves the view instead of drawing.
In Plan, turn Move OFF or choose your drawing tool. In Survey, place with one finger and navigate with two. Select / move edits a device rather than placing one.
A wall will not move in Survey.
Return to Plan / Zone Maker for building edits. For locked Plan objects, check Locks before trying again.
Fill area does nothing or fills the wrong place.
Select the correct zone. Check that the boundary is made of drawn walls, not just an imported picture, and close gaps. Try Outline for a boundary you need to draw manually.
Devices jump to different positions.
Survey uses the shared field grid. Changing grid spacing can realign devices. Undo an unwanted change and choose the grid before building circuits.
Detectors disappear in Plan or in an export.
Fire Plan only displays its limited plan-symbol set. Switch to Survey, check Layers, and choose the Site survey export for all surveyed devices.
I lost the drawing while zooming.
Choose Fit, then zoom back in. Check the active floor and whether the background is hidden.
Finish As-Fit is unavailable.
Complete every created circuit on that floor, close any Manual Edit gaps and resolve circuits flagged after Survey changes. Addressable loops must return to the FAP.
I cannot see my project after switching devices or apps.
Check Show all and the project search. Local projects do not sync automatically; import the editable backup into the new browser or APK.
Saving, import or export fails.
Keep the project open. Save an editable backup if possible. Check available device storage; try a smaller image, a single floor or Standard PNG. Record the exact message before retrying. Do not clear browser data to troubleshoot an unbacked-up project.

16 · Send feedback that helps fix the beta

Go to Start testing → Send feedback. Choose your device, area tested and impact. Include:

  • What you were trying to do, with the exact buttons or gestures.
  • What happened and what you expected instead.
  • Whether it happens again, and the shortest steps to reproduce it.
  • Phone/tablet model, browser or Android APK, and the build shown in the app you used.
  • A screenshot or screen recording, attached through your chosen sharing app if useful. Avoid including customer details that should not be shared.

Share report opens your device’s sharing options. Copy report copies the text so you can send it yourself; copying alone does not submit anything. If your installed build differs from the portal version, write the actual build in the notes.

For a practical test, try a multi-floor project, a small grid, device edits, a full circuit with an intentional correction, both export types and a backup import. Explain which step cost you time as well as what broke.
