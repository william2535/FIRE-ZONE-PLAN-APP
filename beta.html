FIELD CHECKLIST
[ STRESS IT LIKE A REAL JOB ]
  1. Create a project, import a plan or start blank, then draw a few rooms and zones.
  2. Switch floors and confirm each floor keeps the exact zone state you left behind.
  3. Open Survey and add a panel plus several devices. Move and zoom while placing them.
  4. Open Circuit Builder and switch floors there too. Try conventional and addressable routing if possible.
  5. Stress Build mode: ON for separated placement/moving, OFF for combined place + move on a smaller plan.
  6. Complete a circuit, use Undo/Retry once, keep it, then generate the As-Fit preview.
  7. Export something, return Home, close the browser/app, reopen and confirm the project still survives intact.
KNOWN CONDITIONS
[ USEFUL BETA NOISE ]
Dense real-world drawings, rough one-handed routing and awkward mobile layouts are exactly what help. Please push the Build mode toggle, multi-floor switching, Manual Edit, rotation/resize and saved-draft reloads. If anything feels confusing, fragile or slower than doing it on paper, report it.
